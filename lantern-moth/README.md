# Lantern Moth

A night-garden survival game. Keep your moth's light alive: eat glowing orbs, build combos, dodge bats, thorns and spiders, and survive the Great Gray Moth.

Built with TypeScript, Vite and HTML5 Canvas. No backend; progress is saved in localStorage.

## Run locally
1. Install Node.js (LTS) from https://nodejs.org
2. `npm install`
3. `npm run dev` and open the address it prints
4. `npm run build` creates the deployable site in `dist/`

## Controls
Drag, mouse, WASD or arrows to move. Space or double-tap to dash. P or Esc pauses.

## Deploy
Push to GitHub and import the repo in Vercel (framework: Vite), or run `npx vercel`.
